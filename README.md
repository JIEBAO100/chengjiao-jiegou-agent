## 一、这个项目解决什么问题

看K线只能看到「价格走到了哪里」，看不到「这些成交是怎么打出来的」。

同样是上涨 2%：一种是主力真金白银在买、卖压被一点点吃掉；另一种是主力一边拉抬一边出货、散户在往上接。**这两种形态在价格图上几乎一模一样，在成交结构上却完全不同。**

本项目从交易所公开的逐笔成交出发，做三件事：

1. **按金额把成交量拆成大单 / 中单 / 小单** —— 分档线不是写死的金额，而是跟着该币种自己的成交分布走；
2. **用十二个订单流特征量给三种资金行为打分** —— 主力吃货（吸筹）/ 主力出货（派发）/ 散户乱交易；
3. **给出盘面结论** —— 主力真实吸筹 / 主力诱多出货 / 纯散户行情无主力，并同时列出支持证据与反对证据。

## 二、怎么用

### 方式一：网页（推荐给普通用户）

打开页面即可，无需注册、无需密钥：

1. 选择市场（永续合约 / 现货）
2. **在搜索框输入币种代号**（如 `BTC`、`SOL`，支持全部近千个合约 / 两千个现货对）
3. 选择周期（默认 1 分钟）与观察窗（参与统计的时间桶数量）
4. 页面开始每 2 秒「滚雪球」采集逐笔成交，样本够了自动出结论

> 结构类结论需要若干个**已完结**的时间桶：1 分钟档约 6 分钟出结果，周期越长等待越久。
> 样本不足时页面显示「数据积累中」，**不会用任何假数据凑结论**。

### 方式二：命令行 / AI Agent（本作品同时是一个技能）

## 四、算法要点（简版）

**分档尺子（自适应）**

```text
中单线 = max(单笔成交额中位数 × 3, P75)
大单线 = max(单笔成交额中位数 × 10, P95)
两条线至少拉开 2 倍；阈值做 EMA 平滑（系数 0.2），避免每来一批数据就换线
```

**十二个订单流特征量**：大单净流入占比、大单成交占比、主动方向纯度、价格冲击弹性、时间集中度、大单占比漂移、大小单背离、散户追涨度、资金与价格背离、小单主导度、节奏稳定性、中单占比。

**三态判定**：三种行为各打 0–100 分，取最高分作为结论；领先不足 8 分判「结构模糊」；结论切换有 10 分迟滞，避免来回跳。

**成交结构时间轴**：按时间桶逐个拆解（用桶的成交额直方图汇总，覆盖窗口内全部逐笔），与卡片数字共用同一套阈值。

## 五、技术实现

- **纯原生前端**：零第三方库、零 CDN。图表（K线、成交结构时间轴）都是 Canvas 自绘，避免外部资源加载失败导致白屏。
- **双通道取数**：
  - K线 / 币种列表：云端接口代理优先（Netlify Functions，带缓存），浏览器直连兜底；
  - 逐笔成交：浏览器直连优先（2 秒级高频，省云端额度），云端代理兜底。
  两条通道口径完全一致，页面顶部如实显示当前使用的通道。
- **滚雪球积累**：交易所公开接口只给最近约 1000 条逐笔，历史靠页面每 2 秒轮询累加；漏单会被如实检测并标记（`partial`），不会假装数据完整。
- **覆盖率自校验**：逐笔累计成交额 ÷ 同期K线成交额，只统计完整跟踪过的已完结桶。
- **本地缓存**：逐笔与时间桶存在浏览器本地，刷新页面可恢复（24 小时内有效）。
- **页面切换币种/市场**：分档阈值与上一轮结论会重置，不沿用上一个币种的尺子。
