      数据来源与技术说明

      • 本页面全部行情（K线、逐笔成交、合约信息）来自各大交易平台公开行情接口，均为真实数据，无任何模拟或演示数据。
      • 逐笔成交接口只提供最近约 1000 条，历史靠页面每 2 秒轮询「滚雪球」积累；轮询间隔内成交超过单次上限造成的缺口会如实标注，绝不假装完整。
      • 覆盖率 = 逐笔累计成交额 ÷ 同期K线成交额，是采集质量的自我校验；只统计完整跟踪过的已完结时间桶。
      • 永续合约逐笔按「张数 × 合约乘数 × 成交价」换算成美元口径后再分档，大小单阈值随该币种自身成交分布自适应，不写死绝对金额。
      • 技术栈为纯原生 HTML / CSS / JS（零第三方库、零 CDN），图表为 Canvas 自绘；逐笔数据优先浏览器直连交易所，断连时自动切换云端代理。
      • 大小单分档不写死金额：中单线与大单线来自该币种自身的单笔成交额分布（中位数倍数 + 高分位护栏，并做 EMA 平滑），换任何一个币种都成立；同一套阈值同时用于「成交结构拆解」与「主力行为研判」，两个面板的数字不会互相打架。
      • 主力行为用三个可复核的分数说话（主力吃货 / 主力出货 / 散户乱交易），最终结论取最高分；三个分数咬得很紧时判「结构模糊」，样本不足时判「数据积累中」，宁可说不知道也不硬给结论。每条结论都同时列出支持证据与反对证据。
      • 结论切换有迟滞机制（新结论要领先旧结论一定幅度才切换），避免页面上判定结果来回跳动。
      • 本工具不连接交易权限、不代客下单、不保存任何私钥或账户信息。
